GitHub workflow

How to contribute your profile card

Work in your own branch, edit only your learner object, then open a pull request for review.

  1. Fork or clone the repository

    If your instructor asks for forks, click Fork on GitHub first. Then clone your copy to your computer. 

    git clone <repository-url>
cd <repository-folder>

  2. Create your own branch

    Use your JSD number or nickname so the branch is easy to review. 

    git checkout -b add-05-faii-card

  3. Find your object

    Open cohort-webpage/data/learners.js, search for your JSD username, and edit only your own profile object.

  4. Fill in your answers

    Replace blank strings with specific answers. Add interests inside the array, for example ["Frontend", "Testing"].

    If you want to be a Team Leader, change roleIntent to "leader" and copy the example leaderAnswers structure.

  5. Preview the webpage

    Open cohort-webpage/index.html in your browser and check that your card looks correct.

  6. Check your changes

    Confirm that only the expected file changed before committing. 

    git status
git diff

  7. Commit your work

    Stage your edited file and write a clear commit message.

    git add cohort-webpage/data/learners.js
git commit -m "Add Faii profile card"

  8. Push and open a pull request

    Push your branch to GitHub, then open a pull request into the main repository. 

    git push origin add-05-faii-card
